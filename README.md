# ArchPortpoliyo 🚀

A static multi-page portfolio site built using HTML, CSS, and a bit of JS.  
Includes Resume and Bio-data sections.

---

## 🛠️ Run Locally
1. run index.html🙂
   OR
1. Start a simple static server:
   - `npx serve .`
   - or `npx http-server`
2. Open in browser:
   - http://localhost:3000
